# 原理图绘制规范

## 1. 适用范围与核心目标

本规范适用于嘉立创 EDA 原理图的新建、重绘、修改和审核。每次操作都应同时满足以下目标：

- 电气连接正确，器件型号、引脚和网络关系明确；
- 图元全部位于有效图框内，不覆盖标题栏；
- 功能分区清楚，主信号流向自然；
- 元器件紧凑但不拥挤，导线简短且易读；
- 电源、GND、网络名称和文字说明按需显示；
- 位号、参数、网络名称与所属对象的关系清楚；
- 最终结果经过实际渲染画面和图元数据双重检查。

### 1.1 规则用语

- **必须 / 不得**：强制要求；
- **应 / 优先**：默认执行，只有明确原因才可例外；
- **尽量 / 可**：推荐做法，可根据当前电路调整。

### 1.2 冲突处理优先级

规则发生冲突时，按以下顺序取舍：

1. 电气正确性与安全性；
2. 用户对当前任务的明确要求；
3. 项目既有规范和已确认的绘图风格；
4. 可读性、无重叠和归属关系清楚；
5. 功能分区与回流关系；
6. 紧凑性和导线长度；
7. 对称、等距等视觉修饰。

不得为了紧凑、对称或美观牺牲电气正确性和可读性。

## 2. 标准执行流程

### 2.1 绘制或修改前

- 确认当前项目、原理图和目标图页，防止修改错误图页；
- 查询目标图页已有器件、导线、网络符号和文字，明确是新增、修改还是空白重绘；
- 枚举并阅读图页已有备注、说明文字和图片标注，把电池类型、工作模式、电压、电流、隔离域和装配选项等整理成约束清单；
- 约束清单必须与器件手册逐项核对，不得因为某种配置更常见而忽略图页已经指定的模式；
- 读取图框、纸张尺寸和标题栏范围，确定可用绘图区；
- 核对器件型号、封装、引脚号、引脚功能和必要外围器件；
- 明确输入、输出、电源、GND、控制、反馈和 NC 引脚；
- 规划功能块、主信号流向、器件相对位置和文字说明区域；
- 阅读参考图或其他图页，只提取布局原则，不复制未授权图元或绝对坐标。

### 2.2 绘制过程中

- 按功能块逐块完成器件、导线、网络符号和说明文字；
- 每完成一个功能块，立即检查连接、方向、重叠、文字归属和紧凑性；
- 发生遮挡时，严格执行第 5 章的避让优先级；
- 任何移动或旋转完成后，都要检查相邻导线端点和网络是否仍然正确；
- 不在未检查当前功能块的情况下继续堆叠后续电路。

### 2.3 保存和交付前

- 执行第 11 章的最终验收清单；
- 获取并查看实际渲染画面，不得只看 API 返回值或坐标；
- 保存后重新查询主要图元、网络符号和关键导线；
- 必要时再次渲染，确认保存前后画面一致；
- 未完成最终验收，不得报告完成。

## 3. 图页、坐标与参考资料

### 3.1 图框范围

- 所有器件、导线、网络符号、标题、说明文字和图片必须位于有效图框内；
- 不得只检查器件原点，还应考虑符号外形、位号、参数和网络名称的实际显示范围；
- 标题栏上方应保留安全间距，任何电路图元不得压入标题栏；
- 绘制完成后，应检查整个功能块的实际包围范围。

### 3.2 嘉立创 EDA API 坐标

- 当前原理图 API 中，较大的 Y 坐标在实际画面中显示得更靠上；
- 电源符号通常使用比主节点更大的 Y 坐标；
- GND 和位于电路下方的标题通常使用比主电路更小的 Y 坐标；
- 不得凭常见屏幕坐标习惯推断上下关系；
- 每次改变坐标后，必须用实际渲染画面确认方向和范围。

### 3.3 参考图与其他图页

参考资料只用于理解以下内容：

- 功能分区和信号流向；
- 电源、GND 和元器件的相对位置；
- 合理的紧凑程度；
- 导线、符号和文字的视觉间距。

除非用户明确要求复制，否则不得直接复制其他图页图元、照搬绝对坐标，或用坐标相同代替独立绘制和视觉检查。

## 4. 总体布局

### 4.1 信号流向与功能分区

- 默认按从左到右阅读：输入在左，处理或控制器件居中，输出在右；
- 电源尽量位于上方，GND 尽量位于下方；
- 控制、反馈和使能支路靠近相关引脚，避免绕行；
- 多个功能块应明确分组，块间保留可辨认的边界；
- 标题和参数说明不得切断主信号路径或挤入器件之间。

### 4.2 元器件位置

- 主芯片作为功能块中心，输入器件在左，输出器件在右；
- 去耦、输入和输出电容靠近对应引脚或节点；
- 相关器件应紧凑放置，同时为导线、位号、参数和网络符号留出正常空间；
- 输入侧存在 EN、反馈或控制分支时，可适当留出支路空间；
- 输出侧没有额外分支时，应缩短输出引脚到输出器件的距离；
- 不得留下明显可缩短的长导线或无功能意义的大面积空白。

### 4.3 对齐与间距

- 器件和节点优先对齐统一网格；
- 功能对应的器件尽量水平或垂直对齐；
- 同类电源和 GND 符号使用一致方向；
- 视觉间距以容易辨认、没有重叠和没有无意义空白为准；
- 不追求机械等距，不得为对称牺牲紧凑性或可读性。

## 5. 对象归属与遮挡处理

### 5.1 文字归属

- 位号、器件名称和值属于对应元器件，应尽量保持库默认相对位置；
- 电源、GND 和网络名称属于对应网络符号，应紧邻符号并保持默认相对位置；
- 移动元器件或网络符号时，所属文字应随本体作为整体移动；
- 使用 API 移动对象后，应重新查询文字属性，确认位号、值和名称已按相同位移同步；
- 不得把文字单独拉远到无法快速判断归属的位置。

### 5.2 遮挡处理优先级

出现导线、符号或文字遮挡时，按以下顺序处理：

1. 移动、缩短或重新对齐相关导线；
2. 移动整个元器件或整个网络符号，让所属文字随本体移动；
3. 调整相邻功能小组的位置，并同步修正连接导线；
4. 只有默认文字方向或位置确实不适合，而且整体移动仍无法解决时，才允许小幅调整文字。

文字单独微调后仍必须紧邻所属对象、方向正常、归属明确。不得为避让简单遮挡而增加复杂折线。

### 5.3 移动后的复核

- 检查器件引脚、导线端点和连接点是否仍重合；
- 检查是否产生断线、重复线段、零长度线或意外短路；
- 检查位号、值和网络名称是否仍贴近正确对象；
- 获取局部渲染画面，确认视觉结果与图元数据一致。

## 6. 导线与连接

### 6.1 基本规则

- 使用水平、垂直的正交走线；
- 能用直线连接时不增加折线，必须转折时减少转折数量；
- 优先选择最短且易读的路径；
- 导线不得穿过器件本体、位号、参数或网络名称；
- 避免回绕、长距离平行线和无意义的跨区连线；
- 普通导线不显示多余的可见网络文字。

### 6.2 节点、分支与交叉

- T 形分支必须使用明确端点或连接点，不依赖导线中点的隐式连接；
- 交叉但不连接的导线必须有明确视觉区别；
- 需要连接的交叉点必须存在有效连接点；
- 导线汇总后应检查实际网络，没有因几何接近产生误连。

### 6.3 紧凑性检查

- 是否可以移动相关器件缩短导线；
- 是否存在无功能意义的长水平线或长竖线；
- 是否可以把电源或 GND 符号直接放到节点上；
- 是否存在重复线、重叠线、零长度线或多余折线；
- 是否为了对称或汇总网络而造成长距离绕线。

## 7. 电源、GND 与网络标识

### 7.1 网络命名

- 常规电源一般使用 `VCC_电压`，例如 `VCC_12V`、`VCC_5V`、`VCC_3V3`；
- 数字、模拟或芯片专用电源可使用 `VDD`、`VDDA`、`VREF` 等项目既有名称；
- 隔离电源增加 `_EX`，例如 `VCC_5V_EX`；
- 常规地使用 `GND`，模拟地使用 `AGND`，隔离地使用 `GND_EX`；
- 同一项目不得混用多套命名规则；
- `GND`、`AGND`、`GND_EX` 和不同电源域均视为不同网络，只有设计明确要求时才可在指定位置连接。

### 7.2 电源符号

- 电源符号尽量位于对应节点上方，方向向上，名称水平可读；
- 能直接放在节点上时，不增加无意义的长竖线；
- 同一局部电路中，同一电源只保留必要的入口标识；
- 隔离电源应与对应的 `GND_EX` 配对，并检查隔离边界没有被普通网络跨接。

### 7.3 GND 符号

- 每个地符号必须显示其原生网络名称：`GND`、`AGND` 或 `GND_EX`；
- 不得隐藏原生名称，也不得用独立文本重复补画；
- 竖直放置时保留库默认方向、文字方向和文字位置；默认间距合适时不得移动名称；
- 横向放置时，符号可旋转，但名称必须保持水平、紧邻符号外侧，不得竖排或单独拉远；
- 横向 GND 应朝向远离芯片本体的一侧；
- 电容下端等常规接地点，GND 尽量直接放在器件下方；
- GND 可直接放在引脚或节点上，不增加零长度导线；
- GND 可以靠近相邻导线，但符号和名称不得与导线实际重叠；
- 发生遮挡时先移动导线，再移动整个 GND 符号，名称必须随符号保持紧邻。
- 通过 API 放置 GND 后，必须立即查询父级 net flag 和原生 `Name` 属性；不能假定 API 结果与界面手动放置的默认显示状态完全一致；
- API 返回原生名称隐藏时，只修改 `valueVisible`，常规竖直 GND 不得同时改动默认名称坐标；
- 横向 GND 必须旋转或移动整个父级 net flag，禁止只旋转符号子图元或单独拖动 `GND` 名称修补方向错误；

### 7.4 同名网络的局部汇总

- 同一功能块内、位置相邻且完全属于同一网络的多个连接点，应优先用短而清晰的导线汇总到一个 GND、电源符号或网络标识；
- 汇总规则适用于 GND、电源和其他同名网络；
- 不得因为位置接近而合并 `GND`、`AGND`、`GND_EX` 或不同电源域；
- 如果汇总会造成长距离绕线、跨越其他信号、破坏功能分区或降低可读性，应保留多个同名符号。

### 7.5 网络标签

- 普通局部连线默认不放置额外网络标签；
- API 创建普通导线时，第一次调用就必须将内部 `net` 字段省略或设为 `""`；非空 `net` 可能直接显示成蓝色文字，不得把它当作隐藏的内部网络标识；
- 禁止先给所有导线写入临时网络名、再批量清空；需要显示名称时应单独使用原生网络标签、电源符号或 GND 符号；
- 只有跨页、跨功能块、距离较远或直接连线会降低可读性时，才使用网络标签；
- 同一局部网络不得重复堆叠同名标签；
- 网络标签不得遮挡引脚号、引脚名、位号或参数。

## 8. 电气与器件检查

- 绘制前核对器件型号、封装、引脚号、引脚名和功能；
- 输入、输出、电源、GND、使能和反馈脚必须连接到正确网络；
- NC 引脚必须放置明确的未连接标记，不得无说明悬空；
- 使能脚固定到电源时，使用短而清晰的本地连接；
- 不得因导线交叉、符号旋转、网络汇总或图元重叠造成意外短路；
- 保存前确认输入、输出、各电源域和各地网络没有误合并；
- 电气检查必须同时依据图元数据和实际渲染画面。

## 9. 文字、标题与参数说明

### 9.1 位号、参数和标题

- 位号、器件名称和参数必须清晰可读，且与所属器件关系明确；
- 同类器件使用一致的文字风格；
- 标题默认放在功能块下方或用户指定位置；
- 标题不得位于电源符号上方、压住电路或进入标题栏；
- 标题与电路主体形成明确对齐，字号突出但不过度占用空间；
- 不得残留测试文字、旧标题、重复标题或图框外文字。

### 9.2 基本参数说明

- 每个独立功能电路旁默认应放置简洁说明，使阅读者不翻手册即可了解用途和重要参数；
- 只展示输入范围、输出值、设计电流、频率、精度、关键阈值或工作模式等重要信息；
- 优先使用 2～5 行短句或键值形式，每行表达一个重点；
- 不得照搬手册整段内容，也不得重复位号和值中已经清楚表达的信息；
- 未确认或依赖具体工况的参数不得写成无条件结论；
- 说明文字靠近对应功能块，但不得挤入主信号路径或破坏紧凑布局。

推荐格式：

```text
Input: ...
Output: ...
Key: ...
PCB Layout Note: ...
```

### 9.3 PCB Layout Note

- 功能说明最后应增加 `PCB Layout Note:`；
- 只写最关键、最容易影响性能或可靠性的 1～3 项要求；
- 内容必须简洁、可执行，例如“输入电容紧贴 VIN/GND”“SW 铜皮最小化”“反馈线远离 SW 节点”；
- 没有特殊要求时，也应给出器件邻近、回流路径或敏感网络避让要求；
- Layout Note 不替代器件手册中的完整布局章节。

### 9.4 手册图片

- 只有文字不足以清楚表达时，才在电路旁放置典型应用图、时序图、曲线或关键表格；
- 图片裁剪到必要区域，并标注器件型号、图号或来源页码；
- 图片不得替代当前原理图的实际连接，也不得遮挡电路或使图页臃肿。

## 10. 典型功能块布局参考

本章只提供相对关系和检查重点，不提供可直接复制的绝对坐标。

### 10.1 LDO

- LDO 居中，输入电容位于 VIN 左侧，输出电容位于 VOUT 右侧；
- 输入、输出电容靠近对应引脚，输出侧无分支时进一步缩短；
- 电源符号位于输入和输出节点上方，电容 GND 位于下方；
- EN 固定到 VIN 时使用短直线分支；
- 芯片侧面 GND 可使用横向符号，但不得压住 VIN、EN 或器件文字；
- NC 引脚放置未连接标记；
- 标题位于功能块下方。

### 10.2 降压 DCDC

- 输入电容靠近 VIN 和功率 GND；
- 开关芯片居中，续流二极管、电感和输出电容按能量流向向右排列；
- SW 节点相关器件靠近，导线短，避免扩大高频回路；
- 反馈线远离 SW 节点和电感，必要时单独引回采样点；
- 相邻且同属功率 GND 的连接可就近汇总，不得跨越不同地网络；
- 标题和参数说明放在主电路下方或侧面空白区。

## 11. 验收清单

### 11.1 绘制前

- [ ] 当前项目、原理图和目标图页正确；
- [ ] 已确认新增、修改或空白重绘的任务类型；
- [ ] 已读取图框和标题栏范围；
- [ ] 已核对器件、引脚和必要外围；
- [ ] 已规划功能块、信号流向和说明区域；
- [ ] 参考资料只用于布局原则，没有未授权复制。

### 11.2 功能块局部检查

- [ ] 主信号从左到右，电源在上，GND 在下或合理侧向；
- [ ] 器件紧凑但不拥挤，导线无明显可缩短部分；
- [ ] 导线、符号和文字没有重叠；
- [ ] 遮挡优先通过移动导线或整个对象解决；
- [ ] 位号、值和网络名称仍保持在所属对象的默认或紧邻位置；
- [ ] 普通导线没有多余可见网络文字；
- [ ] 所有本次新增或修改的普通导线均已查询，内部 `net` 为空；
- [ ] 相邻同名网络已合理汇总，没有误合并不同电源或地；
- [ ] 每个地符号均显示正确、清晰的原生网络名称；
- [ ] 每个地符号作为完整父级对象检查过方向，未通过单独移动名称掩盖符号反向或压线；
- [ ] 引脚连接、控制脚和 NC 处理正确；
- [ ] 功能说明简洁，并以 `PCB Layout Note:` 收尾；
- [ ] 所有新增图元仍位于有效图框内。

### 11.3 最终电气检查

- [ ] 关键引脚、器件数量和值符合设计要求；
- [ ] 输入、输出、电源和各地网络没有误合并；
